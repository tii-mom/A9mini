# A9 交互滑块物理动力学参数微调与触感调优规范 (Slider Physics Spec v2.0)

---

## 一、物理参数微调对比 (Physics Tokens Comparison)

| 动力学参数 (Physics Token) | v1.0 (原基准) | v2.0 (微调优化版) | 调优工程原因与体验改善 |
| :--- | :--- | :--- | :--- |
| **吸附达标阈值 (`snapThreshold`)** | `0.85` (85%) | **`0.80` (80%)** | 85% 在单手大屏触控场景下拇指边缘伸展过度，容易产生脱手误触；降至 80% 显著提升单手完成率，同时彻底杜绝意外触发 |
| **磁吸吸附完成时长 (`duration-snap`)** | `200ms` | **`160ms`** | 吸附阶段加快 40ms，进入终点更清脆利落，增强智能合约上链“即刻射出”的紧迫感 |
| **阻尼回弹贝塞尔曲线 (`ease-spring`)** | `cubic-bezier(0.175, 0.885, 0.32, 1.275)` | **`cubic-bezier(0.22, 1.2, 0.36, 1.0)`** | 优化冲量阻尼比，抑制多余高频震荡，回弹首波冲顶后迅速平稳衰减归零 |
| **未达标释放回弹时长 (`duration-rebound`)** | `220ms` | **`190ms`** | 回弹响应更迅捷，不拖泥带水 |
| **触控压感缩放比例 (`touchDownScale`)** | `0.96` (96%) | **`0.94` (94%)** | 按下手柄时形变压感更扎实，视觉凹陷深度增强 |
| **多段机械齿轮感刻度 (`hapticSteps`)** | 每 25% 一次 | **每 20% (0.2, 0.4, 0.6, 0.8) 一次** | 完美匹配 80% 吸附点，滑块在达到 80% 时恰好触发第 4 档临界震动，紧接着衔接成功触感 |

## 二、生产级物理滑块逻辑代码 (Production TypeScript & CSS)

```typescript
/**
 * A9 交互滑块核心动力学控制器 v2.0
 */
export class A9SliderController {
  private container: HTMLElement;
  private handle: HTMLElement;
  private fillBar: HTMLElement;
  private maxDrag: number = 0;
  private currentProgress: number = 0;
  private isDragging: boolean = false;
  private lastHapticStep: number = 0;

  // 微调优化后的关键物理参数
  public static readonly SNAP_THRESHOLD = 0.80; // 80% 吸附阈值
  public static readonly SPRING_EASING = 'cubic-bezier(0.22, 1.2, 0.36, 1.0)';
  public static readonly REBOUND_DURATION = 190; // ms
  public static readonly SNAP_DURATION = 160; // ms

  constructor(container: HTMLElement, handle: HTMLElement, fillBar: HTMLElement, onConfirm: () => void) {
    this.container = container;
    this.handle = handle;
    this.fillBar = fillBar;
    this.initEvents(onConfirm);
  }

  private initEvents(onConfirm: () => void) {
    const startDrag = (clientX: number) => {
      this.isDragging = true;
      this.maxDrag = this.container.clientWidth - this.handle.clientWidth - 8;
      this.handle.style.transition = 'none';
      this.fillBar.style.transition = 'none';
      this.handle.style.transform = `scale(0.94)`;
      // 触感：按下轻微压感
      (window as any).Telegram?.WebApp?.HapticFeedback?.impactOccurred('light');
    };

    const onMove = (clientX: number, startX: number) => {
      if (!this.isDragging) return;
      const deltaX = Math.max(0, Math.min(clientX - startX, this.maxDrag));
      this.currentProgress = deltaX / this.maxDrag;

      // 实时位置与填充条同步
      this.handle.style.left = `${deltaX + 4}px`;
      this.fillBar.style.width = `${(this.currentProgress * 100)}%`;

      // 每 20% 触发一次机械刻度感
      const currentStep = Math.floor(this.currentProgress / 0.20);
      if (currentStep > this.lastHapticStep && currentStep <= 4) {
        (window as any).Telegram?.WebApp?.HapticFeedback?.selectionChanged();
        this.lastHapticStep = currentStep;
      } else if (currentStep < this.lastHapticStep) {
        this.lastHapticStep = currentStep;
      }
    };

    const endDrag = () => {
      if (!this.isDragging) return;
      this.isDragging = false;

      if (this.currentProgress >= A9SliderController.SNAP_THRESHOLD) {
        // [判定成功] 吸附至 100% 并锁定
        this.handle.style.transition = `all ${A9SliderController.SNAP_DURATION}ms cubic-bezier(0, 0, 0.2, 1)`;
        this.fillBar.style.transition = `all ${A9SliderController.SNAP_DURATION}ms cubic-bezier(0, 0, 0.2, 1)`;
        this.handle.style.left = `${this.maxDrag + 4}px`;
        this.fillBar.style.width = `100%`;
        this.handle.style.transform = 'scale(1.0)';
        
        // 成功上链双重触感
        (window as any).Telegram?.WebApp?.HapticFeedback?.notificationOccurred('success');
        onConfirm();
      } else {
        // [未达标] 阻尼回弹复位
        this.handle.style.transition = `left ${A9SliderController.REBOUND_DURATION}ms ${A9SliderController.SPRING_EASING}, transform 120ms ease`;
        this.fillBar.style.transition = `width ${A9SliderController.REBOUND_DURATION}ms ${A9SliderController.SPRING_EASING}`;
        this.handle.style.left = `4px`;
        this.fillBar.style.width = `0%`;
        this.handle.style.transform = 'scale(1.0)';
        this.lastHapticStep = 0;
        
        // 阻尼回弹微触感
        (window as any).Telegram?.WebApp?.HapticFeedback?.impactOccurred('medium');
      }
    };

    // 绑定原生 Touch 与 Mouse 事件...
  }
}
```
