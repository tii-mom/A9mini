# A9 Telegram Mini App 核心交互动效与手势规范 (Motion & Haptic Spec)
*版本: v1.0.0 | 设计系统: Obsidian Terminal (华尔街高频量化风格)*

---

## 1. 动效设计哲学与核心原则 (Motion Principles)

A9 的动效遵循**「高频交易终端的物理机械感与链上确认的确定感」**：
1. **零多余修饰 (Zero Latency Pretense)**：杜绝拖泥带水的缓慢弹性动画，交互反馈必须控制在 `120ms ~ 280ms` 内，传递纳斯达克/芝加哥商业交易所级的敏捷度。
2. **状态确定性 (State Certainty)**：链上操作与资金划转通过色彩梯次充能、微光波纹 (Shimmer) 与骨架锁死，给予用户无可置疑的资金安全感。
3. **触感协同 (Haptic Synergy)**：每一处像素运动均深度绑定 Telegram Mini App 原生触感 API (`window.Telegram.WebApp.HapticFeedback`)。

## 2. 核心操作动效深度规范

### 2.1 滑块确认为核心的操作 (Swipe to Confirm / Claim)
> **应用场景**：参与确认页 (`SCREEN_50`)、提取奖励页 (`SCREEN_20`)、续期确认。

#### 交互阶段与参数：
| 交互状态 | 视觉表现 (Visual) | 物理参数 / 曲线 | 原生触感反馈 (TG Haptic) |
| :--- | :--- | :--- | :--- |
| **初始待命** | 滑块手柄带有右向绿色能量脉冲（箭头序列渐进点亮 `0.8s` 循环） | `opacity: 0.4 -> 1.0`, `ease-in-out` | 无 |
| **按住 (TouchDown)** | 滑块按钮微缩至 `scale(0.96)`，轨道背景显示微光轨道高亮 | `duration: 100ms`, `cubic-bezier(0.2, 0, 0, 1)` | `impactOccurred('light')` (轻击) |
| **拖拽中 (Dragging)** | 轨道背景被翠绿能量条 (`#00f090`) 实时填充跟随；当拖拽距离 `< 80%` 时松手弹回原点 | 弹回动画: `duration: 220ms`, `cubic-bezier(0.175, 0.885, 0.32, 1.275)` (轻微阻尼回弹) | 每跨越 25% 刻度触发 `selectionChanged()` |
| **阈值吸附 (Snap, ≥85%)** | 阻尼消失，滑块自动磁吸至终点，箭头图标形变为勾选图标或旋转 Loader | 磁吸吸附: `duration: 140ms`, `cubic-bezier(0, 0, 0.2, 1)` | `impactOccurred('medium')` (段落感强击) |
| **上链广播成功 (Success)** | 轨道向外迸发一道环形扩散波纹 (`scale(1.05)`, `opacity: 0`)，全屏浮现绿色安全锁存印章 | 扩散波纹: `duration: 350ms`, `ease-out` | `notificationOccurred('success')` (成功双击) |
| **超时/风控拦截 (Error)** | 滑块瞬时变为警示红 (`#ff3b57`)，触发左右 `±8px` 剧烈震动 3 次后重置回起点 | 震动序列: `0%, 100% { x: 0 } 20%, 60% { x: -8px } 40%, 80% { x: 8px }`, `duration: 300ms` | `notificationOccurred('error')` (失败重震) |

### 2.2 24 根小时 K 线与实时走廊波动 (Candle Matrix & Market Fluctuation)
> **应用场景**：挑战首页观察阶段 (`SCREEN_56`)、榜单核算矩阵 (`SCREEN_10`)、凭证详情 (`SCREEN_16`)。

#### 波动与收盘更新逻辑：
1. **当前正在交易根 (The Active 16th/Current Hour Candle)**：
   - **呼吸光晕 (Active Pulse)**：柱状体顶部或整体叠加 `00f090` (阳线) 或 `ff3b57` (阴线) 呼吸光晕，周期 `1.6s`，`box-shadow: 0 0 12px rgba(0,240,144,0.6)`。
   - **毫秒级价位跳动 (Price Ticker Pulse)**：当 TWAP 预言机喂价更新时，数字背景以透明度 `0.2` 的淡绿/淡红底色闪烁 `120ms`，数字采用等宽字体平滑翻转切换 (`tabular-nums`)。
2. **整点收盘定盘 (Hourly Bar Finalization)**：
   - 当第 N 根小时结束，该根柱体执行**「凝结上锁」**动效：由高亮脉冲态变为实心锁定量化柱，耗时 `240ms`。
   - 伴随达标阈值进度条（例如 `12 -> 13`）的平滑填充推进动画：`width` 过渡采用 `cubic-bezier(0.25, 1, 0.5, 1)`，耗时 `400ms`。
   - 触发 TG 触感：`impactOccurred('heavy')`，提示本小时走廊已成功锁定。
3. **黑洞销毁态 (Blackhole Liquidation Animation)**：
   - 若未达标判定触发，K 线走廊由荧光绿以波浪序列向右依次坍缩为深红并变为灰暗 (`filter: grayscale(1)`)，柱体伴随下坠淡出效果 (`transform: translateY(6px)`, `opacity: 0.3`)。

### 2.3 倒计时与早鸟降档危机感 (Countdown & Stepped Decay)
> **应用场景**：参与阶段 (`SCREEN_58`)、预热倒计时 (`SCREEN_46`)、异常倒计时。

1. **最后 10 分钟冲刺态 (Final 600s Urgency)**：
   - 毫秒/秒级数字跳动时，边框流光旋转动效（Conic Gradient 流光边框，旋转周期 `3s`）。
   - 倒计时数字在小于 1 分钟时字体颜色从 `#00f090` 变为黄色橙色警示色，秒针跳动伴随极轻微缩放 `scale(1.04)`。
2. **早鸟权重降档瞬时 (2.0x -> 1.4x Transition)**：
   - 顶格卡片徽章“2.0x 极速权重”产生一个碎裂收缩动效，新数字“1.4x”从下方弹入，附带黄色 Warning 边缘闪烁与提示 Toast。

---

### 2.4 数据增量翻牌器与结算入账 (Slot Counter & Roll-up)
> **应用场景**：我的收益主页 (`SCREEN_22`)、结算达标页 (`SCREEN_54`)、队长管理收益 (`SCREEN_30`)。

1. **数字滚轮翻牌 (Number Odometer)**：
   - 收益数值变化时，不使用直接生硬的文字替换，采用基于 CSS `transform: translateY` 的 0~9 垂直滚动数字滚轮，总滚动持续时间 `800ms`，采用减速缓动 `cubic-bezier(0.1, 0.9, 0.2, 1)`。
2. **资产入账流星辉光 (Asset Inflow Glow)**：
   - 资金入账时，卡片顶部划过一道 45 度的镭射白绿辉光条（宽度 40px，横扫卡片，耗时 `450ms`）。

## 4. Telegram WebApp Haptic 触感映射表

在 Telegram Mini App 环境下，所有视觉反馈均精准配合以下标准 SDK 调用：

```typescript
// A9 原生触感调度封装
export const A9Haptic = {
  // 滑块拖拽过程刻度齿轮感
  sliderTick: () => window.Telegram?.WebApp?.HapticFeedback?.selectionChanged(),
  
  // 滑块吸附就绪
  sliderArmed: () => window.Telegram?.WebApp?.HapticFeedback?.impactOccurred('medium'),
  
  // 链上广播/结算完成
  txSuccess: () => window.Telegram?.WebApp?.HapticFeedback?.notificationOccurred('success'),
  
  // 风控拦截/额度用尽/签名拒绝
  circuitBreak: () => window.Telegram?.WebApp?.HapticFeedback?.notificationOccurred('error'),
  
  // 切换Tab与K线模式
  tabSwitch: () => window.Telegram?.WebApp?.HapticFeedback?.impactOccurred('light'),
  
  // 整点小时走廊收盘锁定
  candleClose: () => window.Telegram?.WebApp?.HapticFeedback?.impactOccurred('heavy')
};
```
