## 1. 动效设计令牌 (Motion Design Tokens)

### 1.1 缓动曲线 (Easing Curves)
```css
:root {
  /* 基础微交互：开关、Tab 切换、按钮点击反馈 */
  --ease-standard: cubic-bezier(0.2, 0.0, 0, 1.0);
  
  /* 强调/入场动效：弹窗打开、卡片滑入、抽屉展开 */
  --ease-decelerate: cubic-bezier(0.0, 0.0, 0.2, 1.0);
  
  /* 退场动效：Toast 消失、弹层关闭 */
  --ease-accelerate: cubic-bezier(0.4, 0.0, 1.0, 1.0);
  
  /* 物理弹簧与阻尼回弹：滑块未达阈值复位、拉动刷新 */
  --ease-spring-damping: cubic-bezier(0.175, 0.885, 0.32, 1.275);
  
  /* 翻牌器/数字滚轮递减减速曲线 */
  --ease-counter-roll: cubic-bezier(0.1, 0.9, 0.2, 1.0);
}
```

### 1.2 时长规范 (Duration Tokens)
```css
:root {
  --duration-instant: 100ms;  /* 触控反馈、按下微缩 */
  --duration-fast: 200ms;     /* 列表项展开、小图标状态切换 */
  --duration-normal: 300ms;   /* 视图平移、Tab 切换、弹窗升起 */
  --duration-slow: 450ms;     /* 抽屉大尺寸展开、图表渲染 */
  --duration-sweep: 1800ms;   /* 流星横扫、光斑循环、能量呼吸 */
  --duration-candle-pulse: 1600ms; /* K线盘口博弈微颤周期 */
}
```

## 2. 7 大核心动效实现参数清单与代码示例

### 2.1 实时 K 线博弈微颤与整点收盘 (Real-time Candle & Close)
- **触发场景**：挑战首页 · 观察阶段。
- **视觉逻辑**：正在波动的第 16 根 K 线产生 `scaleY` 物理微颤（0.95 ~ 1.05），顶部微光标尺倒计时跳动。
```css
@keyframes candle-forming-jitter {
  0%, 100% { transform: scaleY(1); filter: drop-shadow(0 0 4px rgba(0, 240, 144, 0.4)); }
  35% { transform: scaleY(1.05); filter: drop-shadow(0 0 10px rgba(0, 240, 144, 0.7)); }
  70% { transform: scaleY(0.96); filter: drop-shadow(0 0 3px rgba(0, 240, 144, 0.3)); }
}

.candle-active {
  transform-origin: bottom center;
  animation: candle-forming-jitter var(--duration-candle-pulse) infinite ease-in-out;
}
```

### 2.2 质押/提取滑块能量轨道与阻尼回弹 (Interactive Slider & Damped Spring)
- **触发场景**：参与确认页 / 领取页。
- **物理阈值**：
  - 触发磁吸完成阈值：`progress >= 0.85` (85%)。
  - 回弹曲线：`--ease-spring-damping` (220ms)。
- **触感序列**：
  - 按下：`Telegram.WebApp.HapticFeedback.impactOccurred('light')`
  - 拖拽分段（每 25%）：`selectionChanged()`
  - 磁吸锁定完成：`notificationOccurred('success')`

### 2.3 资产入账流星辉光横扫 (Asset Inflow Meteor Sweep)
- **触发场景**：挑战首页 · 结算达标 / 个人结算清单。

### 2.4 数字滚轮翻牌器 (Slot Counter Roll-up)
- **触发场景**：参与记录页 / 团队页队长分红。
- **实现机制**：采用 `font-feature-settings: 'tnum'` 等宽排版，配合 JavaScript `requestAnimationFrame` 驱动计数器。

## 3. Telegram WebApp 原生触感 SDK 封装示例 (TypeScript)

```typescript
export class A9HapticEngine {
  private static get tg() {
    return (window as any).Telegram?.WebApp?.HapticFeedback;
  }

  static light() {
    this.tg?.impactOccurred('light');
  }

  static medium() {
    this.tg?.impactOccurred('medium');
  }

  static heavy() {
    this.tg?.impactOccurred('heavy');
  }

  static tick() {
    this.tg?.selectionChanged();
  }

  static success() {
    this.tg?.notificationOccurred('success');
  }

  static warning() {
    this.tg?.notificationOccurred('warning');
  }

  static error() {
    this.tg?.notificationOccurred('error');
  }
}
```

## 4. 移动端触控热区与无障碍 (Touch Target & A11y) 审查结论

1. **最小触控区域 (Target Size)**：所有可点击控件（Tab 导航、操作胶囊、开关、小箭头）均保证物理尺寸或伪元素扩展后 `>= 44x44 pt`（符合 iOS HIG 与 Material Design 标准）。
2. **文本与背景对比度 (WCAG 2.1 AA)**：
   - 核心荧光绿数值 `#00F090` 在深黑底色 `#0A0E17` 上对比度达 **12.4:1**（远超 4.5:1 要求）。
   - 次级信息文本颜色 `#8A93A6` 对比度达 **5.8:1**，确保弱光和夜间环境高可读性。
3. **减少动画偏好支持 (prefers-reduced-motion)**：
   - 在系统开启“减弱动态效果”时，关闭长周期发光横扫与高频微颤，平滑降级为静态高亮展示。
