## 一、前端整体技术栈与架构分层 (Tech Stack & Architecture)

```
+-----------------------------------------------------------------------------------+
|                        Telegram WebApp (TMA) Runtime Layer                        |
|   Window.Telegram.WebApp | BackButton | MainButton | HapticFeedback | CloudStorage |
+-----------------------------------------------------------------------------------+
                                         │
+----------------------------------------▼------------------------------------------+
|                  Core Routing Layer (Hash / Memory-based Router)                  |
|  - App Shell: Tab Frame (`mobile_tab`) vs Stack Frame (`mobile_stack`)           |
|  - Route Guards: Wallet Connect Guard | Genesis Whitelist Guard | Risk Circuit Breaker Guard |
+-----------------------------------------------------------------------------------+
                                         │
        ┌────────────────────────────────┴────────────────────────────────┐
        ▼                                                                 ▼
+───────────────────────────────+               +───────────────────────────────────+
|   Top-Level Tab Routes (4)    |               |      Stack / Sub-Pages (18+)      |
|  - /challenge (挑战首页四阶段)   |               |  - /participate/confirm & success |
|  - /team (团队门面/普通/队长)  |               |  - /warmup/rank & register        |
|  - /leaderboard (战报与排位)   |               |  - /internal/market, buy, records |
|  - /profile (我的资产与凭证)    |               |  - /claim/slider & proof-detail   |
+───────────────────────────────+               +───────────────────────────────────+
                                         │
+----------------------------------------▼------------------------------------------+
|                     Shared Global Store (Zustand / Redux-like)                    |
|  - userStore (address, role: Captain/Member, balanceTon, balanceA9, teamId)       |
|  - roundStore (currentRound: 3, stage: Observation, targetPrice, twap24h, candles)|
|  - riskStore (status: Normal/Warning/Fused, latencyMs, oracleHealth)             |
+-----------------------------------------------------------------------------------+
                                         │
+----------------------------------------▼------------------------------------------+
|                  Design System & Atomic Component Library                         |
|  Atoms (Buttons, Badges, Tickers) -> Molecules (CandleBar, Counters, Sliders)     |
|  -> Organisms (CorridorMatrix, TeamLeaderboard, SettlementCard)                   |
+-----------------------------------------------------------------------------------+
```

| `/risk/audit` | 链上熔断与审计日志 | `mobile_stack` | 预言机状态、TVM 合约验真与异常阻断 |

## 三、原子化组件拆分矩阵 (Component Decomposition Matrix)

### 1. 原子组件 (Atoms)
- `<A9Button variant="primary | outline | ghost" size="sm | md | lg" haptic="light | medium" />`
- `<A9Badge color="cyan | emerald | amber | red" pulse="boolean" />`
- `<A9Address address="string" copyable="boolean" mask="true" />`
- `<A9CryptoTicker symbol="TON | A9" value="number" prefix="string" tabular="true" flashOnUpdate="true" />`
- `<A9ProgressBar value="number" max="number" gradient="emerald | amber" animated="true" />`
- `<A9Switch checked="boolean" onChange="function" haptic="selection" label="string" />`

### 2. 分子组件 (Molecules)
- `<A9CandleStick height="number" isGreen="boolean" isForming="boolean" countdown="string" index="number" />`
  - 封装小时 K 线独立柱体，包含上影线、实体、下影线，以及活跃状态下的 `@keyframes candle-forming-jitter`。
- `<A9SlotCounter value="number" duration="number" easing="--ease-counter-roll" format="comma" />`
  - 纯 JS `requestAnimationFrame` + `font-feature-settings: 'tnum'` 驱动的数值滚轮翻牌器。
- `<A9SliderTracker label="string" threshold="0.80" onConfirmed="function" />`
  - 封装微调后 80% 磁吸吸附阈值与阻尼弹簧回弹的滑块操作器。
- `<A9Drawer title="string" subtitle="string" defaultOpen="false">`
  - 历轮战绩链上哈希抽屉，平滑展开动画。

### 3. 生物体与业务容器 (Organisms)
- `<A9CorridorRadar currentPrice="number" targetPrice="number" candles="CandleData[]" activeIndex="16" />`
- `<A9MeteorCard title="string" totalAmount="string" immediateAmount="string" />`
  - 注入 45 度白金流星扫光的结算凭证卡片。
- `<A9CaptainConsole stats="CaptainStats" topMembers="Member[]" />`
- `<A9RankList items="RankItem[]" userRank="8" cutoffRank="50" />`
