## 1. 测试网准备（极速档：`testnet-fast`，质押 120s / 观察 60s）

在 `~/.config/acton/wallets/global.wallets.toml` 准备测试网钱包并确保测试网 TON 余额充足：
- `deployer`（建议 ≥ 6 TON，用于部署 `JettonMaster` + `RoundController`）
- `treasury`（建议 ≥ 1 TON，接收 100 亿 A9 后自动向 `RoundController` 注资 82 亿）
- `opener` / `keeper`（测试网可复用同一钱包，建议 ≥ 1 TON）
- `teamWallet`（接收达标轮按比例释放的团队 A9）
- `promoHotWallet`（推广奖励热钱包，放 1~2 TON 启动底金 + 适量测试 A9）

## 2. 一步部署 4 合约到 Testnet

```bash
cd /Users/yu1/Desktop/A9mini/ops
export PATH="$HOME/.acton/bin:$PATH"

OPS_EXECUTE=1 OPS_CONFIRM=YES \
  A9_DEPLOY_WALLET=deployer \
```

部署完成后记下输出的 `A9_JETTON_MASTER_ADDRESS`、`A9_ROUND_CONTROLLER_ADDRESS` 和 `RC_JETTON_WALLET`（核对余额严格等于 `8,200,000,000 A9`）。

## 3. 端到端闭环验收项（逐项打钩）

1. **开第 1 轮（`OpenRound`）**：
   ```bash
   OPS_EXECUTE=1 OPS_CONFIRM=YES \
     A9_ROUND_CONTROLLER_ADDRESS=<rc_addr> \
     A9_OPENER_WALLET=opener \
     node scripts/round-ops.mjs --profile testnet-fast --action open-round --round 1 --twap 0 --target 232000 --execute
   ```
   - 验收：`get_protocol_state().currentRoundId == 1`，质押窗口打开 120 秒。
2. **真实钱包参与质押与异常退款**：
   - 测试用户发送标准 TEP-74 转账（`forwardTonAmount = 0.15 TON`，payload `0x5254000F + roundId=1`）到 `RoundController`。
   - 验收：`StakeTicket` 自动部署并记录本金与早鸟权重；再发一笔 `< 1,000 A9` 的转账，确认当场原路退回 A9（无退款子合约）。
3. **单笔结算与达标秒领（`SettleRound` + `TicketClaim`）**：
   - 等待 120s 质押 + 60s 观察结束，由 `keeper` 单笔提交结算：
     ```bash
     OPS_EXECUTE=1 OPS_CONFIRM=YES \
       A9_ROUND_CONTROLLER_ADDRESS=<rc_addr> \
       A9_KEEPER_WALLET=keeper \
       node scripts/round-ops.mjs --profile testnet-fast --action settle-round --round 1 --qualified 18 --candle-hash 0x1234 --execute
     ```
   - 验收：无 6h 冷静期，立刻 `SUCCEEDED`；`teamWallet` 收到按比例释放的 A9；用户调用 `sendV15TicketClaim` 立刻收到 100% 本金 + 20% 立即奖励。
4. **失败轮对称销毁验证**：
   - 开第 2 轮并质押，结算传入 `--qualified 10`，核对本金 100% 销毁 + 一半奖池销毁 + 当轮团队份额销毁 + 第 1 轮锁定份额销毁 1 份（`burnedSlices == 1`）。
5. **推广奖励 `0.06 TON` 热钱包闭环验证**：
   - 启动 `A9mini/worker` 并配置 `A9_PROMO_HOT_WALLET_ADDRESS`，用户通过 `sendV15PromoFee` 转 `0.06 TON`（带 `claim:<id>` 备注），确认热钱包发 A9 且找零回热钱包、热钱包 TON 净增加。
6. **Telegram 真机视口验收（390×844）**：
   - 核对 `?mode=live` 只读与真实签名流程、底栏不遮挡、完整数字无缩写、零 Emoji。
