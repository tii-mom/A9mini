# 小程序深度体验复查

本轮在当前本地工作区检查，范围为广场、闯关、战队、我的、奖励、商城、记录、设置、规则、邀请、群绑定和失效凭证。浏览器视口为 390×844 中文亮色、360×844 英文暗色。Demo 和候选 Testnet 只读模式共 48 组页面均无 pageerror、无页面横向溢出、主内容可见主按钮不超过一个。截图和检测数据存于 output/playwright/deep-review 与 deep-review-live。

## 本轮修复

- 广场主卡置顶，强化轮次、阶段与计时，个人资产放到主卡下方。
- 领取确认移除无数据来源的实际 Gas 区间，明确钱包确认与链上最终扣费，推广固定服务费单列。
- 奖励页解锁规则改为默认折叠。
- 英文只读标识支持换行，增加容器高度防止遮盖。
- 闯关价格区域为两列，限制标签折行，窄屏缩小图标，保持完整价格。
- 失效凭证返回当前规范的轮次记录列表。
- 结算达标徽章同时说明完整分母与通过门槛，失败进度条限制在 0–100%。

## 仍需后续验证

- 当前历史 wealthverse-browser.mjs 仍包含旧页面选择器，不能直接代表本轮完整浏览器验收。本轮另用当前路由执行读取与截图检查。
- 本轮真实模式未连接个人钱包，因此资产授权、交易签名、购箱到账、锁仓凭证与领取到账均需 Telegram 手机专项验证。
- 所有截图为桌面 Chromium 移动视口截图。iOS/Android 安全区、键盘、Tonkeeper 回跳需原生客户端验证。
- Demo 奖励页存在冲价中凭证同时带可领取演示金额的历史样例，后续应统一演示样例的轮次与奖励状态，再验证领取流程。
- 规则页和奖励页的业务说明仍有压缩空间。金额、扣除比例、激活条件需要保留，辅助解释可继续下沉。
- 本轮没有产生同条件性能采样，不能据布局变化声称启动提速。

回归结果为 Node 124/124、Bot 4/4、锁定合约哈希 8/8。修改在工作区，提交与候选发布另行安排。
