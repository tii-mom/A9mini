## 页面和依赖

| 页面 | 入口 | 数据与操作 |
|---|---|---|
| 主城 | /challenge | 轮次阶段和达标进度取自 data.js，角色试穿仅保存在演示内存中 |
| 挑战台与确认 | /round、/challenge/confirm、/challenge/success | 保留阶段切换、预言、确认和凭证路径。live 显示 A9 质押风险和只读门禁；旧 TON 参与表单仅演示 |
| 挑战塔 | /observation/records | 每个格子映射一个时段；未收到确认资料可标为数据暂缺 |
| 宝库 | /rewards、/claim | 全网成功次数取自 config.poolState.successCount，展示三档规则。个人资产缺乏可信数据时等待核验 |
| 图鉴 | /gallery、/gallery/1 至 /gallery/9 | 单卡预览、演示试穿、PNG 导出。角色名称可配置 |
| 商会与邀请 | /team、/team/profile、/team/bind-tg、/team/invite | live 钱包资料走既有用户接口；加入商会复用 joinTeam；海报在本机生成 |
| 排名 | /leaderboard、/warmup/rank | 演示榜使用独立夹具。真实预热邀请榜读取 Worker；其他未接入的榜单显示待核验 |

| 辅助功能 | /warmup、/internal/market、/internal/records、/settings、/risk/matrix、/risk/audit、/rules | 保留入口、语言与明暗设置；预热接口保留；live 内盘购买禁用 |

## 复跑

在项目根目录启动前端。

~~~sh
node a9-mini-app/dev-server.mjs
~~~

另开终端运行回归。浏览器脚本使用已有 Playwright 和 Chromium；如未安装在本项目，PLAYWRIGHT_MODULE 指向可导入的 Playwright ESM 文件，CHROMIUM_PATH 指向 Chromium。截图默认保存到 output/wealthverse。

~~~sh
node --test worker/tests/*.test.mjs a9-mini-app/js/*.test.mjs
node ops/scripts/selftest.mjs
(cd v15 && shasum -a 256 -c ci/artifacts.sha256)
node a9-mini-app/tests/wealthverse-browser.mjs
~~~

## 待项目方决定和待实测

- **身份**。称谓、各等级持仓门槛、价格源和过期时间、质押及奖励的估值口径、历史永久解锁记录待确定。目前可导出演示角色预览卡，真实身份及真实晋升海报等待可信晋升事件。
- **资产**。现有 Worker 在部分 getter 失败时返回零，还会忽略失败的凭证查询。前端保留不确定状态，只展示可识别的正余额和已返回的凭证。完整的个人销毁金额、已解锁且未领取金额、历史领取明细需要可核验来源。
- **业务与美术**。个人、商会及综合邀请排名待接入真实排名来源。图鉴使用临时插画，角色正式原画、独立高阶场景与动画待美术交付。旧辅助页面沿用原有交互并共享新主题，部分既有内容仍仅提供中文。
- **设备与性能**。已在本地 Chromium 验证两种视口和系统减少动效偏好。Telegram iOS / Android 真机安全区、低端机帧率、弱网耗时、相机扫码和系统分享面板待实测。
- **链上与发布**。本地 live 检查使用隔离接口样本。正式钱包读取、测试网/主网资金闭环、生产服务和发布准备度须按 docs/06-v15-主网修复与独立验收.md 独立验收。
