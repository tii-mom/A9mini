# 财富进化世界美术交接

## 场景与交互

主城采用夜空、远景建筑、等距塔楼和独立角色前景。场景保持深色，让金色入口在浅色外壳里也能被看到。桌面指针悬停时场景缓慢位移，人物有轻微待机动作。触屏按下主按钮会产生位移反馈。身份卡切换有转面入场，挑战塔亮窗同时显示数字、文字和颜色。成功绿与未达标红只用于结果，观察中使用琥珀色。系统减少动态效果时停用上述持续或入场动画。

| 用途 | 颜色或材质 |
|---|---|
| 深色画布、面板 | 午夜紫 #171329、#25203A |
| 浅色画布、面板 | 雾紫 #F1ECF9、#FFFAFF |
| 身份边框、主要入口 | 金边 #DFBC89、浅金至蜜金渐变 |
| 图鉴导航、次要操作 | 幻想紫 #8151BD，暗色模式 #BB90FA |
| 塔窗 | 达标 #225B52、未达标 #75354E、观察 #74511F |
| 数字与标签 | 沿用 Inter、JetBrains Mono 和系统中文字体回退。金额带资产单位，支持换行 |

## 角色生产规格

九个立绘使用统一画框，脸部居上、足底靠近下沿，左右保留道具余量。交付大图、圆形头像安全裁切和卡面三套。卡面上保留可变文字区。称谓可在 js/wealth-art.js 调整。

|---|---|---|
| A1 链上萌新 | 便帽、斜背包 | 初入城门，轻装行走 |

| A5 牛市先锋 | 金饰、角形护肩 | 主城广场，冲锋姿态 |
| A6 巨鲸玩家 | 海蓝披风、鲸尾形衣摆 | 港湾领航，宽肩剪影 |
| A7 生态领主 | 枝形科技冠、翡翠权杖 | 林冠领地，幻想坐骑 |
