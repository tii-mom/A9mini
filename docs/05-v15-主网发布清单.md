## 1. 主网单签热钱包清单（纯单签方案 · 支持 3 GRAM 精简起步）

> 注：TON 链原生代币已于 2026-06-15 更名为 **GRAM**（底层公链仍称 TON）。当前 `mainnet` 部署参数已按极简储备金优化（`JettonMaster 0.25` + `Mint 0.30` + `RoundController 0.80` + `Funding 0.15`，部署 4 步净消耗约 **1.12 GRAM**，合约余额后续随时可直充）。

| 角色（Acton 钱包名） | 职责与权限 | 3 GRAM 精简起步 | 宽裕推荐 | 初始 A9 分配 | 备注 |
|---|---|---:|---:|---:|---|
| **`deployer` / `treasury` / `keeper`**（起步可合用，后续再拆 `keeper`） | 部署 4 合约 + 铸 100 亿弃权 + 锁 82 亿 + 开轮（`0.1 GRAM/轮`）与结算（`0.3 GRAM/轮`） | **2.50 GRAM**（部署净耗 ~1.12，余 ~1.38 够跑 3~4 轮） | 10 + 5 GRAM | **10,000,000,000 → 留存 1,800,000,000** | 铸完 100 亿后 `JettonMaster.adminAddress` 自动清零，永久不可增发 |
| **`promoHotWallet`**（可兼 `presaleHotWallet`） | 0 合约推广发币（用户自付 `0.06 GRAM`）与内盘自动发币（收 `5..200 GRAM` → 发 A9，找零回本钱包） | **0.50 GRAM**（上线即自循环） | 2 GRAM | 按当期营销 + 内盘额度分批转入 | 建议与 `treasury` 物理隔离，降低热钱包暴露面 |
| **`teamWallet`** | 接收达标轮按实发比例自动释放的团队 A9（总池 12 亿） | **0 GRAM**（纯收款，提币时再转 Gas） | 0.5 GRAM | 0（随达标轮自动到账） | 纯收款地址，建议独立保管 |

*极简折中提示*：3 GRAM 预算仅覆盖主网部署与前 3~4 轮链上 Gas，**不含** STON.fi 建池流动性资金；内盘成交或社区回流 GRAM 后，可随时向 `RoundController` 和 `keeper` 补充储备金。

## 2. 基础设施与外部配置清单

| 类别 | 配置项 | 说明 |
|---|---|---|
| **链上 RPC** | `TONCENTER_API_BASE` + `TONCENTER_API_KEY` | 主网必须配置付费或注册级 TonCenter API Key，避免免费档 1 req/s 限流 |
| **代币元数据** | `A9_METADATA_URI` | 确认 `a9.json`（名称、符号 `A9`、9 位小数、图标 URL）已部署到正式 HTTPS 域名且可公网访问 |
| **前端与钱包** | 正式 HTTPS 域名 + `tonconnect-manifest.json` | 托管 `A9mini/a9-mini-app/`，确保 `manifest.json` 的 `url`、`name`、`iconUrl` 指向正式域名 |
| **Worker API** | Cloudflare Worker (`A9mini/worker/wrangler.toml`) + D1 (`schema.sql`) | 执行 `wrangler secret put TONCENTER_API_KEY` 注入密钥；配置 `A9_ROUND_CONTROLLER_ADDRESS`、`A9_JETTON_MASTER_ADDRESS`、`A9_PROMO_HOT_WALLET_ADDRESS`、`A9_PRESALE_HOT_WALLET_ADDRESS`、`A9_PRESALE_RATE_A9_PER_TON`、`A9_PRESALE_MIN_ORDER_TON=5`、`A9_PUBLIC_ORIGIN`、`A9_TG_BOT_HANDLE` |
| **Telegram Bot** | Bot Token + Mini App Menu URL | 指向正式版 `https://<your-domain>/?mode=live&api=https://<your-worker-domain>`，支持 `startapp` 归因深链（`bet_` / `burn_` / `round_` / `proof_`） |
| **初始流动性** | STON.fi A9/USDT 池 | 从 `treasury` 的 18 亿留存中拨付初始流动性（参考 5% = 500,000,000 A9 配对应 USDT），建池后即可开启第 1 轮 |

## 3. 主网部署固定执行顺序（全部带强门禁）

1. **复核 4 份合约编译产物哈希**：
   ```bash
   cd /Users/yu1/Desktop/A9mini/v15 && shasum -a 256 -c ci/artifacts.sha256
   ```
2. **主网部署 Dry-run 预检**：
   ```bash
   cd /Users/yu1/Desktop/A9mini/ops && node scripts/selftest.mjs && node scripts/deploy-v15.mjs --profile mainnet --dry-run
   ```
3. **主网正式部署 4 合约 + 铸 100 亿弃权 + 锁 82 亿**（需显式三道门禁：`--execute` + `OPS_EXECUTE=1` + `OPS_CONFIRM=YES` + `OPS_CONFIRM_MAINNET=YES`）：
   ```bash
   OPS_EXECUTE=1 OPS_CONFIRM=YES OPS_CONFIRM_MAINNET=YES \
     A9_DEPLOY_WALLET=deployer A9_TREASURY_WALLET=treasury \
     A9_KEEPER_ADDRESS=<keeper_addr> A9_ROUND_OPENER_ADDRESS=<keeper_addr> \
     A9_TEAM_WALLET_ADDRESS=<team_addr> A9_METADATA_URI=<mainnet_metadata_uri> \
     node scripts/deploy-v15.mjs --profile mainnet --execute
   ```
4. **验证链上状态**：核对 `JettonMaster` 总量 `10,000,000,000 A9`、`mintable == false`、`RoundController` 余额严格等于 `8,200,000,000 A9`。
5. **配置 Worker + 前端上线 + 建池后开第 1 轮**：
   ```bash
   OPS_EXECUTE=1 OPS_CONFIRM=YES OPS_CONFIRM_MAINNET=YES \
     A9_ROUND_CONTROLLER_ADDRESS=<mainnet_rc_addr> A9_OPENER_WALLET=keeper \
     node scripts/round-ops.mjs --profile mainnet --action open-round --round 1 --twap 0 --target 232000 --execute
   ```
