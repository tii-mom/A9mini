## 关键技术选择

1. **零构建改动**：a9mini 是原生 ES Modules 静态应用，不引入打包器。理由：改动面最小，业务逻辑与界面调整可独立验收。
2. **同源代理而不是改 BAM CORS**：BAM `ALLOWED_ORIGINS` 只含 a9.lat。本地代理避免改 BAM，也不把 CORS 放宽带进生产。
3. **持久化白名单**：localStorage 只存语言/视图/续期开关。理由：这是演示数据进入真实模式最短的路径，必须从源头切断。
4. **模式不持久化**：`?mode=` 或 `window.__A9_CONFIG__` 注入，避免浏览器记住演示模式后误判真实环境。
5. **缺值用 null**：目标价未锁定、价格无效、未连接钱包都显示明确状态；0 只表示真实零值。
6. **资金动作先 gating 不接链**：合约版本未交付，真实模式开放任何“看起来成功”的资金动作都会伪造事实。
