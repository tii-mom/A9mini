# a9-mini-app — A9 · 财富大冒险（纯任天堂第一方触感版）

Telegram Mini App 静态前端，采用**纯正任天堂第一方触感 UI**（雪白中性面 `#F4F5F8` / 任天堂正红 `#E60012` / Switch 深石墨炭暗夜主题 `#121318`），零渐变、零发光、纯平实体触感层级与统一矢量图标，面向手机竖屏（390×844 及 320px 窄屏）与横屏安全区自适应。

## 核心架构与特性
- **视觉体系**：90% 洁净中性底色 + 8% 任天堂正红 `#E60012` 行动焦点 + 2% 任天堂四色语义规范（晴空蓝 / 翡翠绿 / 金币金 / 莓红），默认雪白亮色主题（`data-theme="light"`），支持切换石墨暗夜主题（`data-theme="dark"`），内置可选触感交互音效与震动反馈。
- **四核心主导航（`广场 / 闯关 / 战队 / 我的`）**：
  - **广场（`#/challenge`）**：本轮状态、当前参考价与已确认 1H 判定均价区分、12 格冲价印章、奖池与主按钮，四宫格业务入口（宝箱商城 / 免费宝箱 / 12H 预言 / 下轮预热）、我的动态（优先展示待激活奖励）与战队动员入口。
  - **闯关（`#/round`）**：实时价格作战看板、12H 冲价 6×2 印章盘、头矿 6H 5% 止损窗口、0 GRAM 12H 预言擂台、每轮 100,000 A9 空投公示与锁仓入场确认流程。
  - **战队（`#/team`）**：实时战况条、未加入 / 队员 / 队长三态首屏、一键动员喊单中心、TG 群三步核验、6% 商城直推与 8% 好友通关返佣明细及排行榜。
  - **我的（`#/profile`）**：按「资产 → 可领取 → 进行中 → 我的记录 → 提醒与设置」排序，分来源展示可用、可领、待解锁与待激活余额，直达闯关凭证、商城订单、收支账本与系统设置。
- **历史形象系统说明**：原 Boxheads 角色头像、等级解锁、装备与图鉴展示已于现役前端退役；历史 `#/gallery`、`#/gallery/:id` 与 `startapp=gallery_*` 链接继续兼容并导向简洁历史说明页；`assets/boxheads/`（36 张素材与清单）按项目约定保留归档。
- **严格模式隔离**：默认开启本地演示模式（按需懒加载 `demo-data.js`）；`?mode=live` 为真实只读模式，不混用任何演示金额、演示凭证或假哈希。
