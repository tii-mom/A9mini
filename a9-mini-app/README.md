# a9-mini-app — A9 · 财富大冒险（纯任天堂第一方触感版）

Telegram Mini App 静态前端，采用**纯正任天堂第一方触感 UI**（雪白中性面 `#F4F5F8` / 任天堂正红 `#E60012` / Switch 深石墨炭暗夜主题 `#15161A`），零渐变、零发光、纯平实体触感层级与多色矢量图标，面向手机竖屏（390×844 及更窄视口）与桌面宽屏自适应。

## 核心架构与特性
- **视觉体系**：90% 洁净中性底色 + 8% 任天堂正红 `#E60012` 行动焦点 + 2% 任天堂四色语义规范（晴空蓝 / 翡翠绿 / 金币金 / 莓红），默认雪白亮色主题（`data-theme="light"`），支持切换石墨暗夜主题（`data-theme="dark"`），内置可选触感交互音效（默认静音）。
- **四核心主导航（`广场 / 闯关 / 战队 / 我的`）**：
  - **广场（`#/challenge`）**：动态轮次阶段焦点卡（奖池、实时倒计时、目标价/判定均价走势、24H 进度轨、唯一主 CTA）、四宫格任天堂矢量服务入口（宝箱商城 / 免费宝箱 / 奖金金库 / 闯关指南）、下一轮预热卡、24H 预言速览与每日集章打卡。
  - **闯关（`#/round`）**：12H 冲价观测盘与 3×4 印章速选板、头矿 6H 止损窗口条、0 GRAM 12H 预言擂台与锁仓入场确认流程。
  - **战队（`#/team`）**：战队名片、成员列表、邀友奖励（6% 直推返佣）与财富排行榜。
  - **我的（`#/profile`）**：个人身份铭牌栏（Boxheads 收藏头像 + 360° 翻转预览 + 图鉴入口）、资产概览与一键滑块领奖、凭证收藏册（支持 3D 翻面核验与海报导出）、收益账本、自动连闯配置与系统偏好设置。
- **严格模式隔离**：默认开启本地演示模式；`?mode=live` 为真实只读模式，不混用任何演示金额、演示凭证或假哈希。
